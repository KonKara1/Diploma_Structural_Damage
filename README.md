# Diploma_Structural_Damage

Αυτό το αποθετήριο περιέχει τον πηγαίο κώδικα (`main.py`) για τη διπλωματική μου εργασία στο Τμήμα Μηχανικών Η/Υ και Πληροφορικής (CEID) του Πανεπιστημίου Πατρών. 

Η εφαρμογή μέσω της αυτοματοποίησης, βοηθά την επιθεώρηση τεχνικών έργων χρησιμοποιώντας αεροφωτογραφίες (drones) και το μοντέλο ανίχνευσης αντικειμένων YOLO11, ενώ διαθέτει γραφικό περιβάλλον (GUI) γραμμένο σε PyQt6.

## Απαιτήσεις (Requirements)
Για να τρέξει ο κώδικας σε ένα τοπικό περιβάλλον (π.χ. venv ή Anaconda), απαιτείται η εγκατάσταση των παρακάτω βιβλιοθηκών της Python:
- `PyQt6` (Για το γραφικό περιβάλλον)
- `ultralytics` (Για το μοντέλο YOLO11)
- `Pillow` (Για τη διαχείριση εικόνων και δεδομένων EXIF)

## Εκτέλεση
Αφού εγκατασταθούν οι βιβλιοθήκες, η εφαρμογή εκκινείται τρέχοντας:
python main.py
